## Sobre mim

<img align="right" width="180" src="https://i.pinimg.com/1200x/6e/85/80/6e8580bb84fbe10b190d87b2a80e594b.jpg" />

Sou a Helloysa, desenvolvedora focada em Backend e estudante de Desenvolvimento de Sistemas no SENAI (formação em 2026). Minha trajetória na tecnologia começou em 2020 na área de cibersegurança e, em 2024, migrei para o desenvolvimento web. Foi nessa transição que encontrei no Backend a minha verdadeira paixão.

O que realmente me move é o que acontece por baixo dos panos: desenhar a arquitetura de sistemas, estruturar bancos de dados com lógica impecável e construir aplicações robustas. Gosto de entender a engenharia por trás de cada linha de código para garantir que a estrutura seja limpa e eficiente.

Hoje, dedico minha rotina corrida ao treinamento de alta performance como Competidora Web Technologies, transformando lógica complexa em soluções prontas para resolver problemas reais de mercado.
